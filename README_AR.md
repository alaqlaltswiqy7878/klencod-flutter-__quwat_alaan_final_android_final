# قوة الآن — النسخة النهائية بعد إصلاح البناء

هذه النسخة تعالج خطأ البناء الظاهر في سجل Klencod. كان السبب أن ملف `lib/main.dart` قد استُبدل بكود جزئي يبدأ بعناصر واجهة مثل `TextField` خارج أي Widget أو دالة، ويحتوي على `await` و`import` في أماكن غير قانونية. تمت استعادة ملف الدخول Flutter الصحيح الذي يعرّف `main()` و`QuwatAlaanApp` ويشغّل الصفحة الرئيسية.

## الإصلاحات الإضافية

تم رفع `targetSdk` إلى 35 ليتوافق مع Android الحديث وصلاحيات الإشعارات. تم تصحيح اسم التطبيق الظاهر إلى «قوة الآن». تم فصل رقم إشعار التأجيل عن أرقام الإشعارات الأسبوعية حتى لا يلغي أحدهما الآخر، مع توسيع إلغاء الإشعارات عند تحديث المهمة. كما أصبح التأجيل يرفض الوقت المتداخل مع مهمة أخرى، وأصبح قسم «حاليًا» في السجل يظهر فقط عند اختيار تاريخ اليوم.

## المميزات الرئيسية

يضم التطبيق إدارة مهام مع بداية ونهاية وتكرار يومي أو أسبوعي ووصف وتصنيف ودرجة أهمية ومهام فرعية. يمنع التداخل الزمني عند الإضافة والتعديل وإنشاء المهمة من المساعد والتأجيل. ويضم خريطة اليوم، وسجلاً مستقلاً لكل يوم، وأقساماً للحالية والقادمة وغير المكتملة والمؤجلة والمكتملة.

يوفر المساعد المحلي إدخالاً صوتياً عربياً مستمراً، وإرسالاً عند الضغط على زر المربع، وقراءة الردود صوتياً، وإضافة مهمة خطوة بخطوة، ومعرفة المهمة الحالية والقادمة وعدد مهام اليوم. كما يوجد زر مساعد سريع في الشاشات الثانوية.

## البناء

من جذر المشروع شغّل:

```bash
flutter pub get
flutter analyze
flutter build apk --release
```

إذا كان Linux لا يسمح بتشغيل Gradle Wrapper مباشرة، نفّذ:

```bash
chmod +x android/gradlew
```

ملف `android/local.properties` لا يُضمّن عادةً في ZIP لأنه يعتمد على مسار Flutter في جهاز البناء؛ ينشئه Flutter عند تنفيذ `flutter pub get` أو عند فتح المشروع في Android Studio.
